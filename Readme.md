# 实验室本科生入组考核任务说明

你好！欢迎参与实验室的入组考核。
本次考核旨在评估你在科研工作中最常用的几项基础技能：**数据可视化、学术文档排版以及数据集工程（可选）**。科研不仅需要理论创新，更需要扎实的工程动手能力和对细节的极致把控。

请仔细阅读以下三个测试任务的要求。建议在一个统一的工作目录下完成所有任务，并在最终提交时打包为一个压缩文件。

---

## 📁 测试1：科研绘图 (Data Visualization)

高质量的插图是学术论文的“门面”。本任务考察你的代码实现能力、对数据可视化的审美，以及对细节的敏锐度。

* **输入文件：** 文件夹内包含三张参考图（`2021-2024年合同数与金额增长趋势.png`、`对比度.png`、`社会物流数据统计图.png`）。
* **任务要求：**
    1. 请使用 Python（推荐使用 Matplotlib 或 Seaborn 库）尽可能**1:1 复现**这三张图表。
    2. 图表中的数据你可以根据原图进行合理估算（或自行生成 mock 数据，数据具体数值不影响评分，主要考察视觉呈现）。
    3. 注意观察并还原原图中的细节，包括但不限于：色彩搭配、坐标轴刻度、图例位置、字体类型（学术常用如 Times New Roman 或 Arial）、线型与标记等。
* **提交物：**
    1. 绘图的 Python 源代码（`.py` 脚本或 Jupyter Notebook `.ipynb`，代码需包含必要的注释）。
    2. 代码运行生成的最终图片（要求高分辨率，如 `dpi=300`）。

---

## 📁 测试2：文档格式调优 (Document Formatting)

规范的排版是论文投稿的基本要求。本任务考察你阅读官方排版规范的能力以及对文档编辑软件（Word/LaTeX）的熟练度。

* **输入文件：**
    * `《智能科学与技术学报》论文模板.doc` （目标期刊的官方格式模板）
    * `graphrag_vecrag(2).pdf` （待排版的原始内容）
* **任务要求：**
    1. 请将 PDF 中的文本、公式等内容，**完美迁移并排版**到《智能科学与技术学报》的 Word 模板中。
    2. **针对原文档中的图表：你可以直接使用截图工具从 PDF 中截取并插入 Word 中，无需考虑截图的最终清晰度，本次重点考察的是图表的排版占位、图注的格式规范以及图表与正文的交叉引用。**
    3. 严格遵守模板中的所有格式要求（如：各级标题字体字号、段落行距、图表标题位置、参考文献引用格式等）。
    4. 如果遇到公式，请使用公式编辑器（或 MathType）重新规范输入。
* **提交物：**
    1. 排版完成的 Word 文档（`.doc` 或 `.docx`）。
    2. 由该 Word 导出的 PDF 文档（用于跨平台格式核对）。

---

## 📁 测试3：图片标注（可选，但强烈推荐）

在计算机视觉（尤其是 YOLO 等目标检测/实例分割模型）的研究中，高质量的数据集是模型性能的基石。本任务考察你的工具调研能力、环境配置能力以及对数据的严谨态度。

* **输入文件：**
    * `images/` 文件夹（包含多张待标注的原始图片）
    * `dataset.yaml` （类别配置文件）
* **任务要求：**
    1. **工具调研与配置：** 自行调研并选择一款主流的计算机视觉标注工具（如 LabelImg, Labelme, CVAT 等），在你的电脑上完成环境配置并跑通。
    2. **数据标注：** 根据 `dataset.yaml` 中定义的类别，对 `images` 文件夹中的所有图片进行标注。标注为实例分割任务。请仔细考虑边缘、遮挡等复杂情况，保持标注框/多边形的紧凑和准确。
    3. **格式导出：** 将标注结果导出为 YOLO 模型可直接使用的标准 TXT 格式。
    4. **技术文档撰写：** 编写一份简短的教程文档，记录你是如何安装工具、遇到什么问题及如何解决的，并总结你在标注过程中总结出的“标注规范”。
* **提交物：**
    1. 生成的 YOLO 格式标注文件（`.txt`，与图片一一对应）。
    2. 工具调研与使用教程文档（`.md` 或 `.pdf` 格式）。
